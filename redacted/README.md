# Redacted rules and prompts

Structure-only copies of `private/prompts/` and `private/knowledge/`, which are private. Headings,
`{{PLACEHOLDERS}}` and YAML keys are kept; all wording and values are removed.
Regenerate with `python scripts/make_redacted.py`. To run the agent or the tests, restore
the real `private/prompts/` and `private/knowledge/` folders from the private store.
